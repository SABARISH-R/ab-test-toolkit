# Real dataset: Cookie Cats

Not committed. To get it:

```bash
git clone --depth 1 https://github.com/ryanschaub/Mobile-Games-A-B-Testing-with-Cookie-Cats /tmp/cc
cp /tmp/cc/cookie_cats.csv data/real/
```

90,189 players of the mobile game Cookie Cats (Tactile Entertainment), randomly assigned to have the first progress gate at level 30 (control) or level 40. Columns: userid, version, sum_gamerounds, retention_1, retention_7. Originally published on Kaggle / DataCamp.
